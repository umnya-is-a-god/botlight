# lightweightbot

Облегчённая версия [mercurykd/vpnbot](https://github.com/mercurykd/vpnbot) (ветка `dev`). Оставлены только Vless (Xray), OpenConnect, AdGuard, Warp, PAC и DNSTT.

Текущая версия указана в файле `VERSION` и показывается в главном меню бота.

### Удалено

* Контейнеры WireGuard ×2 (`wg`, `wg1`), NaiveProxy (`np`), MTProto (`tg`), Shadowsocks (`ss` + `proxy`), Hysteria (`hy`). Вместе с ними их меню, кнопки, статусы, порты, бэкап, скрипты, dockerfile и конфиги.
* Связка nginx с удалёнными сервисами: upstream `np:443`, `location /v2ray`. certbot больше не запрашивает сертификат на naive-поддомен.
* Формат v2ray/xray-JSON: шаблон, кнопки, импорт в v2rayNG и Streisand. Ссылки hiddify и karing.
* Архив sing-box для Windows (служба winsw) и ссылка на него.
* HWID-лимит целиком.
* AWG-ссылка для Vless, Settings → Ports для удалённых сервисов.
* В меню маршрутов Vless — списки subnet, process, package.
* Мёртвый код: около 130 методов, около 20 маршрутов без кнопок, устаревший `offWarp` для старого клиента Cloudflare, недоделанные списки exclude/reverse/subzones, около 35 строк перевода.
* Кнопки и функции: «tun lists» (списки package/process для TUN в mihomo), «set timer» (срок действия пользователя Xray и автоотключение), «qr short» (QR короткой ссылки vless; QR для sing-box остался) и «domains» в маршрутах Xray (второй вход в список доменов PAC; список редактируется в меню PAC).
* Ссылка импорта в Rabbit Hole (`import://rabbit-hole`).
* PAC-файлы для браузера и Shadowsocks-Android (ссылки, кнопки, их сборка `updatepac.php` и выдача по `/pac…?t=pac|mpac`), кнопки импорта готовых списков «community antifilter» и «ru-bundle», скрытая проверка адреса по списку. Список доменов PAC остался: он попадает в подписки (`~pac~` в шаблонах), правки применяются сразу.

### Изменено

* XHTTP: `xmux` у sing-box и mihomo выровнены (без `max_connections`), значения совпадают с `vless://`-ссылкой.
* Telegram API: таймауты cURL 5/15 с, бот больше не зависает намертво.
* sing-box 1.14: `http_client` и `http_clients` вместо `download_detour`.
* Шаблоны `origin` заменены новыми: sing-box 1.14 и mihomo для Android/Windows, `authentication` = `123:321`.
* Главное меню: Vless + OpenConnect, AdGuard + PAC, Warp + Settings.
* Образы собираются на сервере (`botlight/vpnbot-*:local`), а не скачиваются готовыми у автора. Версии ядер под контролем: Xray берётся последний стабильный релиз (или закреплённый в `.env`, `XRAY_VERSION`), в контейнере `php` sing-box 1.14.3 (сборка rule-set'ов) и mihomo 1.19.32. Убран неиспользуемый Qt (`py3-qt5`).
* Исправлен разбор вывода `xray x25519`: на новом сервере публичный ключ Reality получался пустым.
* Исправлено: клавиатура меню PAC (не открывалась бы после удаления кнопки), предупреждение в `addRuleSet()`, `ssh()` теперь требует имя контейнера.
* Безопасность: PHP-FPM принимает соединения только от nginx (`ng`); VPN-клиенты Xray и OpenConnect не могут обращаться к внутренним сетям сервера и хоста (кроме DNS AdGuard у OpenConnect); убран открытый без пароля socks-вход `wg-in` в Xray.
* Безопасность веб-части: закрыто чтение любых файлов через ссылку PAC (`?t=`); редактор и сохранение шаблонов, вход в панель AdGuard доступны только по свежей подписи Telegram от админа; убран небезопасный `unserialize`; секрет в адресах удлинён до 32 символов, у cookie AdGuard отдельный секрет; ввод админа экранируется в shell-командах; удалён неиспользуемый вебхук `/tlgrm`; nginx не отдаёт файлы за пределами папки webapp и скрытые файлы (`.htpasswd` и т.п.).
* Изоляция контейнеров: взлом одного контейнера больше не даёт хоста. Приватный SSH-ключ есть только у `php` и `service` (остальным — публичный, только чтение); `docker.sock` не монтируется никуда, старые образы чистит `make`; `.env`, `.git`, стартовые скрипты и конфиги, которые контейнер только читает, смонтированы только для чтения; `update.sh` и его PID вынесены из папки `update`; бот больше не пишет конфигурацию Docker — включённые порты он сохраняет флагами, а `docker-compose.ports.yml` собирает хост (`scripts/ports.sh`). Все контейнеры запускаются с `no-new-privileges` и без лишних прав (`MKNOD`, `SETFCAP`, `SETPCAP`, `FSETID`, `NET_RAW` — кроме `oc` и `wp`).
* Сетевая изоляция клиентов на уровне контейнеров: трафик клиентов Xray, WARP-прокси и туннеля DNSTT не может уйти во внутренние сети сервера и к хосту, даже если домен резолвится во внутренний адрес (iptables в `xr`, `wp`, `dnstt`; если правила не встали, Xray не запускается, а вход в туннель DNSTT закрыт). SSH во всех контейнерах: вход root только по ключу, проброс портов, X11, туннели и пароли выключены. Учётка DNSTT `vpnbot` может только пробрасывать соединения (`ssh -D`/`-L`), без команд, shell и sftp; при выключенном DNSTT её пароль блокируется.
* Проверка ввода: домены (в т.ч. Reality и DNSTT), ключ AdGuard, IP в списках блокировки, параметр `cdn` и Host в подписках проверяются до записи в конфиги nginx/Xray/certbot; значения в шаблонах подписок экранируются. Первым админом может стать только пользователь в личном чате с ботом. Пароль AdGuard по умолчанию случайный. Rule-set'ы для sing-box компилируются один раз и кешируются.
* Цепочка поставки: sing-box, mihomo, dnslookup и wgcf скачиваются с проверкой SHA-256, Xray — с проверкой по `.dgst` из того же релиза, microsocks собирается из закреплённого коммита, dnstt — из закреплённой версии через Go-модули (проверка по sum.golang.org).
* Базовый образ Alpine 3.18 → 3.24, PHP 8.1 → 8.3.
* Веб-часть бота (подписки, PAC, webapp) работает через PHP-FPM вместо NGINX Unit, который архивирован в октябре 2025 и не поддерживается. nginx в контейнере `ng` передаёт запросы в `php:9000` по FastCGI.
* OpenConnect: `ocserv` 1.6.0 собирается через Meson из релизного архива с проверкой контрольной суммы (сборка из master через autotools больше не работала).
* Warp: из образа убраны AmneziaWG, Go, tun2socks и xtables-addons, которые ему не нужны.
* Убраны остатки списков subnet/process/package, обратный PAC и связанные теги шаблонов.
* DNSTT открывается командой `/dnstt`, кнопки в главном меню нет; его строка статуса появляется в меню, когда задан домен или открыт порт 53.

## Установка с нуля

Для чистого сервера Debian/Ubuntu, выполняется от root. Бот ставится в `/root/vpnbot`. Первый запуск занимает несколько минут: образы контейнеров собираются на сервере.

```shell
wget -O- https://raw.githubusercontent.com/umnya-is-a-god/botlight/main/scripts/init.sh | sh -s YOUR_TELEGRAM_BOT_KEY
```

Сразу после установки напишите боту `/start`: админом становится первый, кто ему написал.

#### Версия Xray

По умолчанию (`XRAY_VERSION=latest` в `.env`) при каждом запуске (`make r`, перезагрузка, обновление через бота) берётся последний релиз Xray с отметкой Latest на GitHub, пре-релизы пропускаются. Если вышла новая версия, образ пересобирается. Чтобы закрепить конкретную версию, укажите её, например `XRAY_VERSION=v26.3.27`.

#### Обновление

Бот раз в час проверяет новые коммиты в этом репозитории и присылает их список с кнопкой «update bot». Вручную:

```shell
cd /root/vpnbot
git pull
make r
```

#### Restart:
```shell
cd /root/vpnbot
make r
```
#### autoload:
```shell
crontab -e
add `@reboot cd /root/vpnbot && make r` and save
```

# lightweightbot

Telegram-бот для своего VPN-сервера: облегчённая версия [mercurykd/vpnbot](https://github.com/mercurykd/vpnbot).

## Протоколы

* **VLESS (Xray)** — транспорт на выбор: Reality, WebSocket, XHTTP. Всё на порту 443.
* **OpenConnect** (ocserv) — на 443, отдельный поддомен.
* **DNSTT** — DNS-туннель (порт 53/udp) до SSH-сервера; включается командой `/dnstt`.
* **WARP** (Cloudflare) — выход в интернет для выбранных доменов и IP через WARP.
* **AdGuard Home** — DNS для всех клиентов: DoH и DoT (порт 853), блокировка рекламы.

## Возможности

* Клиенты VLESS: ссылка `vless://`, подписки для sing-box, mihomo и Happ, импорт в приложения в одно нажатие, QR.
* Шаблоны подписок sing-box и mihomo: свой шаблон на пользователя или общий по умолчанию, редактор в Telegram.
* Маршрутизация: списки блокировки и WARP на сервере, rule-set'ы и список доменов PAC в подписках, профиль маршрутизации Happ (`MYrouting`).
* Трафик по каждому пользователю, сброс вручную или 1-го числа каждого месяца.
* Лимит IP на пользователя: уведомление, если пользователь подключается с большего числа адресов.
* Анализ логов nginx: поиск сканеров, автоматическая блокировка IP, список игнорируемых IP.
* Домен и SSL: Let's Encrypt, свой сертификат или nip.io без своего домена.
* Бэкап: зашифрованный файл в Telegram, автобэкап по расписанию, восстановление на новом сервере.
* Обновление из бота кнопкой «update bot» (настройки сохраняются), автообновление.
* Мост через второй сервер (`/mirror`): домен указывает на мост, ссылки и сертификаты работают через него.
* Безопасность: клиенты VPN не видят внутренние сети сервера, контейнеры изолированы, ввод админа проверяется, загрузки проверяются по контрольным суммам.

## Кнопки

### Главное меню
Статусы сервисов и портов, автофункций. Кнопки: Vless, OpenConnect, AdGuard, PAC, Warp, Settings.

### Vless
* **reset stats** — обнулить трафик всех пользователей; **reset monthly** — обнулять 1-го числа.
* **main outbound name** — тег outbound в шаблонах, куда подставляются параметры сервера (по умолчанию `proxy`).
* **cdn** — домен для ссылок при WS/XHTTP (например, за CDN); пусто — основной домен.
* **ip limit** — `секунды:число_IP`; `0` выключает.
* **RLTY / WS / XHTTP** — транспорт. При XHTTP sing-box недоступен (нет поддержки в sing-box).
* **changeFakeDomain** — сайт, под который маскируется Reality; **steal from yourself** — маскироваться под свой домен.
* **sing-box templates / mihomo templates** — шаблоны подписок.
* **routes** — маршруты (ниже).
* Список пользователей с трафиком; **add** — добавить (`имя` или `имя:uuid`, через запятую несколько); 🟢/🔴 — показать включённых или выключенных.

### Пользователь Vless
* **reset stats** — обнулить трафик пользователя.
* **singbox / mihomo** — открыть конфиг подписки.
* **singbox: … / mihomo: …** — выбрать шаблон пользователя.
* **qr singbox** — QR для импорта в sing-box.
* **rename** · **🟢 on / 🔴 off** (включить/выключить) · **delete**.
* В тексте: ссылки `vless://`, подписки sing-box, mihomo, Happ и ссылки `import://` для импорта в приложения.

### Vless → routes
* **block** — домены и IP, которые сервер блокирует.
* **Warp** — домены и IP, которые идут через WARP.
* **rulesset** — удалённые rule-set'ы в подписках: `outbound[:behavior]:время:URL`.
* **Happ routing** — профиль маршрутизации Happ (`happ://routing/onadd/…`), в Happ называется `MYrouting`; новая ссылка заменяет прежнюю, `-` убирает.

В списках: **add**, 🟢/🔴 (вкл/выкл запись), **delete**, **delete all**, **backup** / **restore** (CSV-файл).

### Шаблоны (sing-box / mihomo)
* **add** — загрузить шаблон файлом (имя — в подписи к файлу).
* По каждому шаблону: имя (открыть в редакторе), **download**, **delete**, 🟢/🔴 — шаблон по умолчанию.
* **origin** — базовый шаблон; **copy** — сделать из него свой.

### OpenConnect
* **change subdomain** · **change secret** (секрет в ссылке входа) · **change password** (общий пароль всех клиентов).
* **add peer** — добавить клиента.
* Список клиентов: имя — карточка с **rename**; **delete** — удалить.

### AdGuard
* **web panel** — панель AdGuard; **third party browser** — открывать её и вне Telegram (по паролю).
* **change password** — пароль панели; **ClientID** — идентификатор для DoT (`<id>.домен`).
* **fill allowed clients** — отвечать только своим клиентам; **delete allowed clients** — снять ограничение.
* **check DNS** — проверить DNS-сервер; **reset settings** — вернуть настройки AdGuard по умолчанию.
* **add upstream** / **delete** — вышестоящие DNS.

### PAC
Список доменов для подписок (тег `~pac~` в шаблонах; в шаблонах origin эти домены идут через VPN). Кнопки как в списках маршрутов.

### Warp
* **warp+ / re-registration** — новый аккаунт и ключи WARP. Отправить: ключ WARP+ — WARP+ с ним; `+` — оставить текущий ключ; `-` — без ключа.

### Settings
* **install domain / delete** — домен; **nip.io** — домен вида `IP.nip.io`.
* **Letsencrypt SSL** / **Self SSL** (свой сертификат файлом) / **renew SSL** / **delete SSL**.
* **Ports** — открыть/закрыть порты 853 (DoT) и 53 (DNSTT), нужен restart.
* **logs** — скачать или очистить логи, **autoclean** — очистка по расписанию.
* **IP ban**: **autoscan** (период проверки), **autoblock**, **notify** (🔊/🔈/🔇), **ignorelist** / **blocklist** (в ignorelist — импорт IP Telegram, Gcore, Cloudflare), **analyze**.
* **language** · **pagination** (строк на странице).
* **backup** — бэкап файлом; **restore** — восстановить; **🔐** — пароль бэкапа (без него бэкап не отправляется).
* **auto backup** — `начало / период`, например `now / 1 day`; **auto update** — обновляться самому.
* **fake html** — страница-заглушка на корне сайта (.html до 1 МБ).
* **branches** — ветка, changelog, **update bot**; **restart** — перезапуск.
* **rebuild images** — пересобрать все образы заново: свежие базовые образы (Alpine, AdGuard Home) и обновления пакетов (PHP, OpenSSL, сертификаты). Контейнеры останавливаются, бот и VPN недоступны на время сборки; образы собираются по одному, итог приходит сообщением.
* **add admin** / **delete <id>** — админы (последнего удалить нельзя).

### Команды
`/menu` (или `/start`) — меню, `/id` — свой id, `/dnstt` — меню DNSTT, `/mirror` — мост через второй сервер: скрипт socat (до этого сервера по IPv4 или IPv6) и IP моста (выключает лимит IP, добавляет IP в ignorelist), `/searchLogs <ip>` — найти IP в логах.

## Установка

Чистый сервер Debian/Ubuntu, от root. Бот ставится в `/root/vpnbot`, первый запуск — несколько минут (образы собираются на сервере).

```shell
wget -O- https://raw.githubusercontent.com/umnya-is-a-god/botlight/main/scripts/init.sh | sh -s YOUR_TELEGRAM_BOT_KEY
```

Сразу после установки напишите боту `/start`: админом становится первый, кто ему написал. Автозапуск после перезагрузки ставится сам (`make uncron` / `make cron` — выключить/включить).

## Обновление

Кнопка **update bot** (бот сам сообщает о новых коммитах). Вручную: `cd /root/vpnbot && git pull && make r`.

Обновления безопасности внутри контейнеров (Alpine, PHP, сертификаты, AdGuard Home) приходят только с пересборкой образов: кнопка **rebuild images** или вручную `cd /root/vpnbot && make d && make rebuild && make u` (`make rebuild S=ad` — только один сервис). Обновление пакетов на хосте (`apt`) их не затрагивает.

Версия Xray: по умолчанию последний стабильный релиз (`XRAY_VERSION=latest` в `.env`); закрепить — например `XRAY_VERSION=v26.3.27`.

## Удаление

```shell
cd /root/vpnbot && make delete
```

Удаляет автозапуск, контейнеры бота, его тома (AdGuard, WARP), образы и папку `/root/vpnbot`. Другие контейнеры и образы на сервере, Docker и пакеты, поставленные установщиком, не трогаются. Перед удалением сохраните бэкап (Settings → backup), если он понадобится.

На втором сервере моста: `sudo bash socat.sh remove`.
